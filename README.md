# Enunciado: Controle de Microservo com Potenciômetro 

Em projetos de IoT, é necessário integrar dispositivos de entrada e saída para realizar ações de controle. Nesta atividade, utilizando o Tinkercad, você deverá integrar um potenciômetro e um microservo ao Arduino, utilizando a leitura da entrada para controlar a posição do atuador.
